# IBM Plex Mono relation arrow

These local subsets contain U+21B3 (↳) in weights 400 and 500. The
Fontsource Latin subsets do not include this code point. `web/styles/fonts.css`
adds it to the existing IBM Plex Mono family using `unicode-range`, following
the local-glyph approach used by timbre-palette.

Source: [Google Fonts subset](https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500&text=%E2%86%B3&display=block).
