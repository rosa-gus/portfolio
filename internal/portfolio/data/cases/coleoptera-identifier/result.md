O protótipo ganhou um fluxo completo, da escolha da fotografia à apresentação de sua hipótese taxonômica, com direito a árvore de classificação, candidatos alternativos, score e aviso científico explícito. A mesma API atende à interface interativa e fornece uma saída JSON para automações, enquanto o carregamento tardio do modelo, contratos tipados e testes determinísticos mantêm a base preparada para evolução. Ainda faltam um classificador binário dedicado para barrar imagens fora de Coleoptera e uma avaliação com dataset representativo.
