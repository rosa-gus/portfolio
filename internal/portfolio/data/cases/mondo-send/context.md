*Mondó*, em tupi antigo, significa “mandar, fazer ir; enviar de cá para lá”.

No GNOME, o envio nativo de arquivos por Bluetooth fica escondido em uma sequência de telas. Para iniciar uma transferência, é preciso abrir as Configurações, acessar o Bluetooth, selecionar um dispositivo, acionar “Enviar arquivos” e então escolher o conteúdo no Nautilus, o gerenciador de arquivos do sistema.

O problema não era a velocidade de transmissão do Bluetooth, mas a quantidade de etapas necessárias para começar. O Mondó nasceu para aproximar essa ação do lugar onde os arquivos já estão.
